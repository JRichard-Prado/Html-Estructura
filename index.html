CE 1.1 — Criterio de Evaluación

Estructura de una página web

Todo documento HTML sigue una estructura jerárquica (árbol) formada por elementos anidados. Pasa el cursor sobre cada línea para conocer su función.

<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8" />
<title>Mi primera página</title>
<link rel="stylesheet" href="estilos.css" />
</head>
<body>
<h1>Bienvenido</h1>
<p>Este es un párrafo.</p>
<a href="otra.html">Ir a otra página</a>
</body>
</html>
<!DOCTYPE>
Declaración de versión HTML. Siempre la primera línea.
<head>
Cabecera con metadatos. No visible en pantalla.
<body>
Cuerpo con contenido visible. Lo que ve el usuario.
Anidamiento
Las etiquetas se abren y cierran en orden correcto.
